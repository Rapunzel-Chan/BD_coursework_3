# Проект BD-parser 

## Описание:

BD-parser - веб-приложение для создания базы данных работодателей и вакансий с возможностью произвести выборку 
по ключевому слову, а также увидеть общее количество вакансий от определенных работодателей, вычисления средней 
заработной платы и выше среднего.

## Установка:

1. Клонируйте репозиторий:
```
https://github.com/Rapunzel-Chan/BD_coursework_3
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:
1. Функции create_database, create_tables, insert_company, insert_vacancy позволяют создать БД с таблицами компании и
вакансии, а также создать столбцы с соответствующими полями;
2. Функции get_company_vacancies, get_company_info созданы для получения данных по работодателям и вакансиям через API 
hh.ru;
3. Класс DBManager и методы get_companies_and_vacancies_count, get_all_vacancies, get_avg_salary, 
get_vacancies_with_higher_salary, get_vacancies_with_keyword созданы для взаимодействия с базой данных, с возможностью 
получить все вакансии, указанных работодателей, вычисления среднего показателя заработной платы, посмотреть вакансии 
с заработной платой выше среднего, а также получить выборку вакансий по ключевому слову.
4. В точке входа, которая находится в main.py, функция format_salary необходима для вывода зарплат, когда не указаны
оба параметра зарплаты, а функция main запускает автоматическое создание БД с информацией от работодателей, список id
которых прописаны в config.py, а также предоставляет возможность пользователю сделать выборку вакансий по ключевому 
слову, в частности, список предоставлен компаний с вакансиями для разработчиков).
